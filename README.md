# Hi, I'm Syafril

GIS analyst and web developer from East Java, Indonesia. I turn spatial data into maps and tools that people can actually use.

### What I do

- **CTO at CV. Alur Kerja Semesta** — building and deploying Nilo, a marketplace for digital products (Next.js, Payload CMS, NestJS, Prisma, PostgreSQL)
- **GIS since 2019** — maps for expeditions, field research, and search-and-rescue operations; trained members of 5+ university nature clubs in GIS and land navigation
- **Statistics Indonesia (BPS)** — processed maps and building-point data for the 2023 Agricultural Census (ST2023)
- **Thesis** — landfill site suitability analysis in Jember Regency using Weighted Linear Combination (WLC)

### Tools

- **GIS:** QGIS · PostGIS · Leaflet

- **Web:** Next.js · React · NestJS · Django · Prisma
